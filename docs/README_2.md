# ESP32-S31-WROOM-3

KiCad schematic symbol and footprint for the ESP32-S31-WROOM-3 module.

Note: this chip isn't widely available yet, but the symbol and footprint are ready if you want to start designing boards around it.

## Contents

- `ESP32-S31-WROOM-3.kicad_sym` — schematic symbol
- `footprint/ESP32-S31-WROOM-3.kicad_mod` — PCB footprint

## Usage

Add this repo as a library in KiCad (Preferences > Manage Symbol Libraries / Manage Footprint Libraries), pointing at the `.kicad_sym` file and the `footprint` folder.
